What the student must do

Build the graph Laplacian, take the Fiedler vector, sort nodes, and sweep balanced prefixes. The continuous embedding becomes a hard bipartition only after the sweep chooses the best legal cut. Report the partition, its cutsize, and its balance.

Implement track

This is Track A: write the code yourself. The command below is the reference check. You can also run the same golden with a button (it switches to the Lab tool).

1. What “done” looks like

Run spectral bisection on the five-node starter. You should land on A–B–C versus D–E with cutsize three and balance 2 vs 3 (side 0 is the Fiedler prefix DE).

parts=ABC|DE cutsize=3 balance=2 vs 3

Fiedler order low→high is E D C B A. The sign of the vector may flip across implementations; the sorted order and the prefix sweep are the contract.

2. What you re-implement

  1. Laplacian L = D − A (weighted).
  2. Fiedler vector: second eigenvector (shifted inverse iteration is enough for n=5).
  3. Sort nodes by Fiedler value.
  4. Sweep balanced prefixes; pick min cutsize; print parts + cutsize + balance.

3. Check the reference (from this lab folder)

python3 common/solvers.py examples/tiny_graph.json

Pitfalls to watch

  • Optimizing cut while ignoring balance — this course always reports both.
  • Taking the sign cut at 0 instead of a prefix sweep. C sits near zero; the sweep, not the sign, picks {D,E}.
  • Hard-coding “negative = left.” Eigenvector sign is arbitrary; sort then sweep.
  • Reporting pairwise cut on a hypergraph instance (not this lab’s graph, but a later trap).
  • Blaming spectral when a multilevel flow is actually a coarsening bug.
